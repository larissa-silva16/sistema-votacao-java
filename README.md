# Sistema de Votação em Java

## Objetivo

Desenvolver um sistema de votação em Java para cadastrar candidatos,
registrar votos e apresentar os resultados.

## Conceitos utilizados

- Arrays
- Matriz
- Loops
- Loops aninhados
- Condicionais
- Métodos
- Scanner
- Validação de dados

## Funcionamento

O sistema permite cadastrar até cinco candidatos, registrar até dez votos
por turma e exibir os resultados da votação.

O programa também verifica entradas inválidas, candidatos inexistentes,
números repetidos e identifica vencedor ou empate.

## Como executar

Compile:

javac src/SistemaVotacao.java

Execute:

java -cp src SistemaVotacao
